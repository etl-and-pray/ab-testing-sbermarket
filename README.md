# A/B Testing & Product Analytics: SberMarket ETA Delivery Optimization

Практический кейс по оценке эффективности нового алгоритма предсказания времени доставки (ETA) в мобильном приложении СберМаркета с помощью A/B-тестирования.

---

## Цель проекта
Спроектировать и проанализировать результаты A/B-эксперимента для нового алгоритма прогнозирования времени экспресс-доставки вместо фиксированного интервала (20–60 минут), оценить влияние изменений на ключевые продуктовые метрики и поведение пользователей.

## Стек и инструменты
* **Python**, Pandas, NumPy, SciPy / Statsmodels (статистический анализ, проверка гипотез)
* **SQL**, Adminer (извлечение и предобработка данных из реляционной базы данных)
* **Jupyter Notebook** (проведение расчетов, визуализация, сторителлинг)

## Основные этапы работы
1. **Дизайн эксперимента:**
   * Формулировка продуктовых и статистических гипотез.
   * Выбор места сплита (экраны выбора магазина, главная страница ретейлера, чекаут).
   * Определение ключевых метрик (метрики бизнеса, пользовательского опыта и качества доставки).
2. **Анализ данных:**
   * Подключение к учебной БД через Adminer, выгрузка и очистка данных о пользовательских сессиях и заказах.
3. **Оценка результатов A/B-теста:**
   * Проверка сплита на корректность (AA/AB-тесты, проверка распределений).
   * Расчет статистической значимости различий между тестовой и контрольной группами (t-тесты, расчет p-value).
   * Интерпретация результатов и подготовка рекомендаций для продакт-менеджера.
